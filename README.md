# VIKALP – AI-Powered Smart Agriculture Rover

### HTH 2.0 | AI • IoT • Robotics • Smart Agriculture

An intelligent agricultural rover designed to support precision farming through AI-based plant disease detection, soil monitoring, environmental sensing, and smart irrigation.

## 🚀 Key Features
- AI-based plant disease detection using YOLO
- Soil moisture monitoring for irrigation assessment
- Temperature and humidity monitoring using DHT22
- Ultrasonic obstacle detection
- Four-wheel robotic mobility
- Water pump for irrigation
- Mobile application for agricultural data monitoring

## 🛠️ Technologies Used
- ESP32-S3
- Python
- YOLO
- Embedded C++
- Kotlin and Android
- Supabase
- IoT

## 🔩 Hardware Components
- ESP32-S3
- 4 × 12V Johnson 500 RPM motors
- 2 × BTS7960 motor drivers
- Soil moisture sensor
- DHT22 sensor
- Waterproof ultrasonic sensor
- 12V DC water pump
- LiPo battery
- Buck converters

## ⚙️ Working Principle
The rover collects soil and environmental data using sensors. Its AI system analyzes plant images to identify potential diseases. Sensor readings support irrigation decisions, while the motorized platform enables movement through agricultural areas.

## 🎯 Objective
To develop a modular smart farming solution that combines AI, embedded systems, robotics, and IoT to improve crop monitoring and support informed agricultural decisions.
